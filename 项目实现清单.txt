Astro 企业官网项目实现计划

Context

用户是 React/Astro 初学者，当前已在 D:\workshop\company-site 初始化了一个 Astro 7 官方 Blog 模板项目。首页已能正常访问（npm run dev）。

最终目标是构建一个可登录的企业官网：
- 前端：Astro
- 认证：Clerk（登录 / 注册）
- 登录后可见 Dashboard，展示企业经营假数据
- 网站包含 Blog 区域
- 用户可在后台新增/管理 Blog 文章
- CMS：pagescms.org（Git-based）
- 部署：Vercel
- 开发工具：Claude Code + CC Switch

实现步骤与学习清单

Phase 0：熟悉 Astro 基础（必学）

目标：看懂当前项目代码，能独立修改页面和组件。

[ ] 学习 Astro 组件语法（frontmatter + HTML 模板）
  资料：https://docs.astro.build/en/basics/astro-components/
[ ] 学习 Astro 文件路由
  资料：https://docs.astro.build/en/guides/routing/
[ ] 学习内容集合 Content Collections
  重点看 src/content.config.ts 和 src/content/blog/
  资料：https://docs.astro.build/en/guides/content-collections/
[ ] 学习 client islands（client:load / client:only）
  资料：https://docs.astro.build/en/concepts/islands/
[ ] 实践：把 src/consts.ts 里的站点标题和描述改成企业信息

Phase 1：改造为企业官网基础结构

目标：把 Blog 模板改造成公司官网的样子。

[ ] 修改 src/consts.ts
  - SITE_TITLE 改为公司名
  - SITE_DESCRIPTION 改为企业简介
[ ] 重写 src/pages/index.astro 为企业首页
  - Hero 区块、公司介绍、服务/产品、联系方式
[ ] 修改 src/pages/about.astro 为公司介绍页
[ ] 修改 src/components/Header.astro
  - 导航改为：首页 / 关于我们 / Blog / 登录
  - 删除 Astro 官方社交链接
[ ] 修改 src/components/Footer.astro
  - 改成公司版权信息和联系方式
[ ] 调整 src/styles/global.css
  - 把博客风格改成企业风格（配色、字体、间距）
[ ] 学习内容：Astro Layouts
  资料：https://docs.astro.build/en/basics/layouts/

Phase 2：集成 Clerk 登录/注册

目标：用户能注册、登录、登出。

[ ] 安装 Clerk Astro SDK
  npm install @clerk/astro
[ ] 在 astro.config.mjs 添加 Clerk 集成
  参考：https://clerk.com/docs/references/astro/overview
[ ] 注册 Clerk 账号并创建 Application
  获取 PUBLIC_CLERK_PUBLISHABLE_KEY 和 CLERK_SECRET_KEY
[ ] 创建 .env 和 .env.example
  注意：.env 不要提交到 Git
[ ] 在 src/components/Header.astro 添加登录/用户头像按钮
  使用 <UserButton />、<SignInButton />、<SignOutButton />
[ ] 创建登录/注册页面
  src/pages/sign-in.astro
  src/pages/sign-up.astro
  使用 <SignIn />、<SignUp /> 组件
[ ] 学习内容：Clerk + Astro 官方文档
  https://clerk.com/docs/references/astro/overview

Phase 3：实现登录后的 Dashboard

目标：只有登录用户能看到 Dashboard，展示假经营数据。

[ ] 修改 astro.config.mjs，设置 output: 'server'
  Dashboard 需要请求时判断登录状态
[ ] 创建 src/pages/dashboard.astro
  使用 Astro.locals.auth() 获取当前用户
  未登录用户重定向到登录页
[ ] 准备假数据
  在 src/data/mockStats.ts 里写死一组经营数据
  示例：营收趋势、订单量、用户增长、产品销量
[ ] 在 Dashboard 展示数据
  可以用简单 HTML 表格 + CSS 卡片
  也可以用图表库（如 Chart.js 或 Recharts）
[ ] 学习内容：
  Astro Server Output：https://docs.astro.build/en/guides/on-demand-rendering/
  Astro Middleware / Locals：https://docs.astro.build/en/guides/middleware/

Phase 4：接入 Pages CMS 管理 Blog

目标：通过 pagescms.org 在浏览器里新增、编辑、删除 Blog 文章。

[ ] 了解 Pages CMS 工作原理
  Git-based，直接修改仓库里的 Markdown 文件
  官网：https://pagescms.org/
[ ] 把项目推送到 GitHub
  git add . && git commit -m "init" && git push
[ ] 在 pagescms.org 连接 GitHub 仓库
  按界面指引配置
[ ] 配置 Pages CMS 的 content schema
  让它识别 src/content/blog/ 目录
  字段映射：title、description、pubDate、updatedDate、heroImage、正文
[ ] 测试：在 Pages CMS 里新增一篇文章，提交后拉取到本地验证
[ ] 学习内容：
  Pages CMS 官方文档：https://pagescms.org/docs/
  Astro Content Collections（已在 Phase 0 学过）

Phase 5：Blog 后台文章管理（站内）

目标：登录用户在网站后台也能新增/编辑文章（可选，与 Pages CMS 二选一或并存）。

说明：如果 Pages CMS 已经能满足需求，这一步可以跳过。如果想在网站内部做，需要更复杂的实现。

[ ] 创建 src/pages/dashboard/posts.astro
  列出当前所有 Blog 文章
[ ] 创建 src/pages/dashboard/posts/new.astro
  表单：标题、描述、日期、正文
[ ] 创建 Astro API endpoint
  src/pages/api/posts.ts 处理 POST 请求
  把新文章写入 src/content/blog/
[ ] 学习内容：
  Astro API Endpoints：https://docs.astro.build/en/guides/endpoints/
  服务端文件写入（Node.js fs）

建议：初学者先只用 Pages CMS 管理文章，跳过站内编辑。等主体功能稳定后再考虑增强。

Phase 6：部署到 Vercel

目标：网站上线，登录、Dashboard、Blog 都能在线上运行。

[ ] 安装 Vercel adapter
  npx astro add vercel
  或手动安装 @astrojs/vercel
[ ] 修改 astro.config.mjs 配置 Vercel adapter
  因为 Dashboard 需要服务端渲染，选择 serverless 模式
[ ] 推送代码到 GitHub
[ ] 在 Vercel 导入项目
  选择 GitHub 仓库
[ ] 在 Vercel 环境变量里配置 Clerk Key
  PUBLIC_CLERK_PUBLISHABLE_KEY
  CLERK_SECRET_KEY
[ ] 配置 Vercel 域名
  默认 xxx.vercel.app
  可选：绑定自定义域名
[ ] 测试线上环境
  首页、Blog、登录、Dashboard 全部走一遍
[ ] 学习内容：
  Vercel + Astro 官方指南：https://docs.astro.build/en/guides/deploy/vercel/

Phase 7：收尾与优化

[ ] 添加站点图标和 SEO
  public/favicon.svg
  src/components/BaseHead.astro 里补充 OG 标签
[ ] 移动端响应式检查
[ ] 暗色模式（可选）
[ ] 404 页面 src/pages/404.astro
[ ] 添加 Loading 状态
[ ] 整理 README.md，记录本地运行和部署步骤
[ ] 清理 test1 旧项目（确认不再需要后）

推荐学习顺序

1. Astro 基础语法 + 内容集合
2. 把首页改成企业首页
3. Clerk 登录集成
4. Dashboard 与假数据
5. Pages CMS + Blog
6. Vercel 部署

关键文件清单

- astro.config.mjs — 站点配置、集成、adapter、输出模式
- src/consts.ts — 站点全局常量
- src/content.config.ts — Blog 内容集合 schema
- src/components/Header.astro — 导航（登录态显示）
- src/pages/index.astro — 企业首页
- src/pages/about.astro — 公司介绍
- src/pages/sign-in.astro / sign-up.astro — 登录注册
- src/pages/dashboard.astro — 后台 Dashboard
- src/content/blog/ — Blog 文章目录
- .env — Clerk 密钥（不提交 Git）
- .env.example — 密钥模板（可提交）

验证方式

- 本地：cd /d/workshop/company-site && npm run dev
- 登录测试：用 Clerk 提供的测试邮箱注册/登录
- Dashboard 测试：未登录访问 /dashboard 应被重定向
- CMS 测试：在 Pages CMS 新增文章，本地 git pull 后刷新页面可见
- 线上测试：访问 Vercel 域名，全流程走通

注意事项

- Clerk 的 Secret Key 绝对不要泄露到前端或 Git
- 部署到 Vercel 前必须切到 output: 'server' 或 hybrid，否则 Dashboard 无法判断登录态
- Pages CMS 是 Git-based，线上内容更新依赖 Git 同步，不是实时数据库
- 当前项目没有安装 React，Dashboard 如果需要复杂图表可以后续安装 React 或 Chart.js
